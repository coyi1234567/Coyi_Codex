商业化与版本规划

该版本为可商用原型：支持移动端体验、埋点扩展位、广告激励位、会员系统拓展位。 产品经理、设计、插画、测试、运营、技术团队可在此基础上快速迭代。

  • 产品经理：提供版本目标、关卡策划、付费点位。
  • 老板：看板实时查看核心指标，随时评估ROI。
  • H5设计师：通过样式变量调整视觉主题。
  • 插画师：替换 assets/ 中的SVG即可更新形象。
  • 技术专家 & 开发工程师：模块化脚本，方便接入小游戏SDK。
  • 产品测试：内置调试面板（控制台命令 window.__nebula.debug()）。
  • 玩家：无需下载，扫码即玩，可添加到主屏。
  • 运营团队：配置 config/campaigns.json（示例）实现活动切换。

    运营与发布手册

    涵盖部署、活动、分析、客服四大流程，支持团队端到端上线。

    自动部署

    1. Fork/拉取代码后运行 npm install。
    2. 执行 npm run build 生成 dist/ 静态文件。
    3. 使用 npm run preview 验证产物或将 dist 上传至任意静态空间。
    4. 如需 CI，可使用 .github/workflows/deploy.yml（模板）接入 Github Pages、阿里云OSS等。

    运营活动

    维护 config/campaigns.json 可配置活动主题、倒计时与奖励信息，脚本会自动读取。

    数据分析

    通过 analytics.track 钩子接入 GrowingIO、神策或自建埋点服务。

    客服支持

    使用 window.__nebula.debug() 导出实时状态，定位玩家反馈问题。

    星云探险队 · 快速上手

    1. 输入昵称开启旅程，系统会记录最佳成绩。
    2. 点击降落的能源即可获得分数，注意能量维持。
    3. 能量条低时使用加速器，危险物体会扣减能量。
    4. 完成阶段后可在运营后台触发活动皮肤。
